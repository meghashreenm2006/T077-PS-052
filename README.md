# Cold-Chain Shipment Temperature Compliance and Claims Engine

**Team ID:** T077  
**Problem Statement:** PS-052

## Project Overview

This project implements a command-driven backend system for monitoring temperature-sensitive shipments in pharmaceutical and frozen-food logistics.

The system processes temperature logger readings, detects excursions, evaluates compliance with product temperature profiles, determines consignment release decisions, calculates carrier penalties, and allocates claims.

## Objectives

- Define product temperature profiles.
- Manage shipments, consignments, transport legs, and hand-offs.
- Process temperature logger readings.
- Detect temperature excursions and data gaps.
- Calculate cumulative excursion minutes.
- Calculate Mean Kinetic Temperature (MKT).
- Determine RELEASE, QUARANTINE, or REJECT decisions.
- Calculate carrier penalties and claims.
- Generate excursion reports, release certificates, and claim settlements.
